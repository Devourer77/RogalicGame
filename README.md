# Rogalic

Пошаговый карточный рогалик в мрачном фэнтези: тактика на сотах, два героя (Маг и Рыцарь), карты, духи стихий, хаб между забегами. 3D, PC.

**Движок:** Godot 4.7 (GDScript) · **Модели:** Blender 5.2 → glTF (`.glb`), собираются скриптами из `assets/models/src/`

## Как запустить
1. Установить [Godot 4.7](https://godotengine.org/download).
2. В менеджере проектов Godot нажать **Import** и выбрать `project.godot` из этой папки.
3. **F5** — игра начинается с главного меню (хаб «Застава Колокола»).

## Что уже есть
- Акт 1 «Гнилые топи»: карта пути из 8 рядов, 20 видов врагов, 14 отрядов, 4 элиты, 2 босса, 6 арен.
- Бой на сотах 12×12: объекты и реакции стихий, прогноз хода врагов, ИИ с характерами.
- Система карт: 107 карт с двумя ветками улучшения, общая Цепь отряда.
- 4 духа стихий с пассивами, Зовом и своими картами.
- Хаб: улучшения за Отзвуки, стартовые колоды, обереги, уровни сложности (Звоны).

## Структура
- `scenes/` — сцены Godot
- `scripts/` — код: `battle/` (логика боя, ИИ, соты), `data/` (ресурсы), `hub/`, `autoload/` (`Run`, `Meta`)
- `resources/` — карты, враги, отряды, духи, реликвии, улучшения хаба (`.tres`)
- `ui/` — экраны и интерфейс
- `assets/` — модели, текстуры, иконки, звуки, шрифты
- `tests/` — тесты: `godot --headless --path . -s tests/<имя>.gd`
- `CLAUDE.md` — правила разработки
